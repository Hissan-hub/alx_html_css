# Headphones Website — ALX HTML & CSS Project

This project is part of the ALX Front-End Specialization.
Your task is to recreate the Headphones Figma design using only HTML and CSS.
The goal is to learn layout structure, responsiveness, typography, and design accuracy.

------------------------------------------------------------
## Project Overview
You must reproduce the provided Figma design exactly.
The Figma file contains the desktop and mobile layouts, fonts, colors, spacing, and images.

------------------------------------------------------------
## Figma Requirements
1. Create a Figma account.
2. Open the project and click "Duplicate to your Drafts".
3. If fonts are missing on your system, install these fonts:

- Source Sans Pro
- Spin Cycle OT

------------------------------------------------------------
## Responsive Requirements
The webpage must switch to the mobile layout when the screen width is 480px or less.

Breakpoints:
- Above 480px → desktop layout
- 480px and below → mobile layout

------------------------------------------------------------
## Interaction Requirements

Links on hover or active:
a:hover,
a:active {
  color: #FF6565;
}

Buttons on hover or active:
button:hover,
button:active {
  opacity: 0.9;
}

------------------------------------------------------------
## Layout Requirements
- Max content width: 1000px (centered)
- Follow the exact spacing, sizes, and colors from Figma
- No JavaScript for this project (HTML + CSS only)
